      Privacy

      No account, no analytics, and no resume database. Resume content, the job description, and non-secret settings are stored in localStorage. In direct mode the API key is memory-only. In secure proxy mode the key stays in a server-side secret and only the proxy URL is saved. DeepSeek receives the job description and resume content only when you run AI selection; contact fields are stripped from the AI payload. When you load a job URL, that URL is read through Jina Reader or a public read-only proxy; the extracted text is saved locally.

      How it works

      ATS-first, not ATS-guaranteed.

      1. Paste the job description or its URL. URLs are read through Jina Reader with a text fallback. The analyzer extracts hard skills, tools, title signals, and years of experience.
      2. Choose how to tailor. Local mode reorders, aligns, bolds, and trims existing content. DeepSeek can also reword the summary and latest role with the same facts; use a memory-only key for this tab or the secure proxy so the key stays server-side. Missing tools are never invented.
      3. Review the gap notes. Each missing keyword says whether it is in your master but not selected, or absent from your resume entirely. Experimentation is treated as supported when your resume already documents A/B tests and hypothesis testing. TypeScript, for example, is only added if your resume contains it.
      4. Review and export. The preview fills two Letter pages without stretching the font. Download the DOCX or print a selectable-text PDF.

      The score is a transparent heuristic: 65% keyword coverage, 10% title fit, 25% format checks. It is not affiliated with Workday, Greenhouse, Lever, or any ATS vendor.
